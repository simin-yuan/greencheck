### Findings

#### `self_assessment.identity_score` — CONSTANT

84/84 samples report the identical value 1.0. Zero variance over the observed window.

#### `self_assessment.memory_recall.recall_rate` — CONSTANT

84/84 samples report the identical value 0.0. Zero variance over the observed window.

#### `self_assessment.memory_recall.recall_rate` — BARE_ZERO

63 of 84 samples examined nothing (_count=0) yet reported 0.0 — the same value produced by samples that examined 3+ items and matched none. The zero is ambiguous: a consumer cannot distinguish 'not examined' from 'examined, no hits'.

#### `guard denial path — 13 full days with zero firings` — DEAD_GATE

27,097 events recorded across 13 days, of which 25,594 were the guard reporting itself healthy, and the denial path fired 0 times. The assertion has never been observed to fire. Its existence is documented; its behaviour is not.

#### `guard denial path — full window` — PASS

## What the failures have in common

Each instrument was correct code. None crashed. None returned nonsense.
Each produced a number on schedule, and each number was read.
What none of them did was vary with the thing it was named after:

- `identity_score` reported 1.0 in every one of the 84 samples. A constant
  cannot carry information about anything.
- `recall_rate` reported 0.0 in every sample. 63 of
  those samples examined nothing at all, and reported the same value as samples
  that examined eight items and matched none.
- `overall` and `reflection_score` each took two values across the ledger, and
  the split between them is exactly the split on one boolean. Neither is an
  independent finding: they are the same bit, reported twice.
- The guard logged 25,594 healthy events over
  13 days and fired 0 times.

## Falsifiers

These results are stated so that they can be wrong:

1. If any instrument above is shown to separate inputs within the dimension it
   claims to measure, the corresponding finding is false.
2. If the guard is shown to have fired before 2026-09-19T14:52:23.011940+00:00 on an input that should have been
   blocked, the DEAD_GATE finding is false.
3. If the anonymisation changed any value (as opposed to a field name), every
   number here is void. `tools/anonymise.py` is the only transform applied;
   it rewrites keys and aggregates the guard log, and its leak check is mandatory.
